# Muhammad Khoirul Yahya — Personal Portfolio

The open-source repository for my personal engineering portfolio: [https://khoirulyahya.github.io](https://khoirulyahya.github.io).

Built with a minimalist, brutalist design philosophy using zero runtime dependencies and plain HTML, CSS, and modern JavaScript.

---

## ⚡ Design & Engineering Highlights

- **Zero-Dependency Architecture**: Built with raw HTML5 and modern CSS3 (no heavy UI frameworks, bundlers, or runtime bloat).
- **Dual-Track Seamless Infinite Marquee**: Hardware-accelerated CSS GPU animation (`will-change: transform`) with infinite gapless loop and hover pause.
- **Interactive Expandable Labs Grid**: Accessible, progressive enhancement toggle (`aria-expanded`) to explore featured vs. extended engineering labs without layout shift.
- **SEO & Knowledge Graph Ready**: Full Schema.org `Person` JSON-LD structured data, Open Graph meta tags, canonical URL, sitemap, and Google Search Console verification.
- **Responsive & Accessible**: Semantic HTML structure, high color contrast, keyboard skip links, and fluid clamp-based typography.

---

## 🛠️ Tech Stack

- **Markup & Styling**: Semantic HTML5, CSS Custom Properties (Variables), CSS Grid & Flexbox
- **Typography**: Inter & System Monospace Font Stacks
- **Hosting**: GitHub Pages with custom apex domain routing
- **Deployment**: Automatic deployment via GitHub Pages main branch
